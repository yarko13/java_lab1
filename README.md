#Лабораторная работа: класс для работы с матрицами комплексных чисел на Java и консольный интерфейс к нему.

Автор: Барашкин Ярослав Александрович, группа 25КНТ3

Возможности:

сложение матриц;
умножение матриц;
деление матриц;
транспонирование;
вычисление определителя;
вычисление обратной матрицы;
ввод комплексных чисел из строки: 3, -2.5, 2i, -i, 1+2i, 3-4i.

Структура проекта:

Complex.java (Неизменяемое комплексное число: сложение, вычитание, умножение, деление, модуль, проверка на ноль, разбор из строки, вывод)  
ComplexMatrix.java (Матрица комплексных чисел и все операции над ней)  
Main.java	(Консольный интерфейс)  

Стандартного типа комплексных чисел в Java нет, поэтому Complex написан с нуля. Он неизменяемый, т.е. каждая операция возвращает новый объект. ComplexMatrix изменяемая, а элементы в ней задаются через set, но операции над матрицами возвращают новую матрицу и не трогают исходные.  

Программа спрашивает операцию, затем нужные матрицы, выводит результат и снова спрашивает операцию.

+:	сложение A + B	

*:	умножение A · B

/: деление A / B

T:	транспонирование

det:	определитель

inv:	обратная матрица

exit:	выход

Матрица вводится следующим образом: сначала число строк, затем каждая строка матрицы отдельной строкой ввода, элементы разделяются пробелами. Число столбцов определяется по первой строке.

Пример: умножение
Операция (+, *, /, T, det, inv, exit): *
Матрица A, строк: 2
A, строка 1: 1 2
A, строка 2: 3 4
Матрица B, строк: 2
B, строка 1: 0 1
B, строка 2: 1 0
[ 2 + 0i    1 + 0i]
[ 4 + 0i    3 + 0i]

Пример: определитель комплексной матрицы
Операция (+, *, /, T, det, inv, exit): det
Матрица A, строк: 2
A, строка 1: 1+i 2
A, строка 2: 3 4-i
-1 + 3i

Пример: ошибка
Операция (+, *, /, T, det, inv, exit): inv
Матрица A, строк: 2
A, строка 1: 1 2
A, строка 2: 2 4
Ошибка: Матрица вырожденная, обратной не существует

Математические решения

Деление матриц: Для матриц деление определено неоднозначно, поэтому принято соглашение A / B = A · B⁻¹ (обратная матрица стоит справа). Это не то же самое, что B⁻¹ · A. Для деления матрица B должна быть квадратной и невырожденной, а число столбцов A должно равняться числу строк B.

Определитель вычисляется методом Гаусса, сложность O(n³). Разложение по строке потребовало бы O(n!) операций. На каждом шаге ведущим выбирается элемент с наибольшим модулем в столбце: деление на малое число накапливает ошибку округления. Обмен строк меняет знак определителя, это учитывается. У вырожденной матрицы определитель равен нулю (исключение не бросается).

Обратная матрица вычисляется методом Гаусса-Жордана: к матрице справа приписывается единичная, строки преобразуются так, чтобы слева получилась единичная, тогда справа стоит обратная. У вырожденной матрицы обратной нет, в этом случае бросается ArithmeticException.

Сравнение с нулём: Числа типа double хранятся приближённо (например, 0.1 + 0.2 != 0.3), поэтому ноль проверяется с допуском: число считается нулевым, если модули обеих его частей меньше EPS = 1e-9. Это используется при выборе ведущего элемента и при делении на комплексное число.

Вывод: Числа округляются до 6 знаков, а почти нулевые части печатаются как 0. Это сделано только для вывода: внутри хранятся точные значения, на вычисления округление не влияет.

Обработка ошибок:

Число строк или столбцов не положительное:	IllegalArgumentException
Размеры не подходят для операции (сложение, умножение):	IllegalArgumentException
Определитель, обратная матрица или деление для неквадратной матрицы:	IllegalArgumentException
Обратная матрица (в том числе при делении) для вырожденной матрицы:	ArithmeticException
Деление на комплексный ноль:	ArithmeticException
Строка матрицы с другим числом элементов, чем первая:	IllegalArgumentException
Число введено в неверном формате:	IllegalArgumentException
Индекс за пределами матрицы (при использовании классов из кода):	IndexOutOfBoundsException

Ограничения реализации технического задания лабораторной работы:

Элементы по модулю меньше 1e-9 считаются нулём, поэтому матрица, целиком состоящая из очень малых чисел, будет признана вырожденной.
Экспоненциальная запись в комплексных числах с мнимой частью (1e-5i) не поддерживается: знак - внутри e-5 принимается за разделитель частей, и программа выдаёт ошибку формата. Для вещественных чисел без i (1e-5) запись работает.
Мнимая единица обозначается только строчной i.
Числа по модулю порядка 10¹² и больше выводятся некорректно из-за округления при печати. Вычисления при этом остаются точными.
Матрицы вводятся только с клавиатуры, чтения из файла нет.
